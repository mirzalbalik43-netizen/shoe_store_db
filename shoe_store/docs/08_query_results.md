# Результаты продвинутых запросов: подзапросы и оконные функции (День 7)

Запросы выполнены через src/db_run_queries.py. Все 11 SQL-запросов (скалярные и табличные подзапросы, операторы IN/EXISTS, оконные функции ROW_NUMBER, RANK, LAG и SUM OVER) выполняются без синтаксических ошибок. Подзапросы корректно вычисляют средние значения, максимумы и списки ID. Оконные функции правильно рассчитывают ранги, накопительные итоги и разницу в датах без схлопывания строк через GROUP BY. Данные выводятся в консоль в виде форматированных таблиц.
