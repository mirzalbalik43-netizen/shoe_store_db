Результаты проверки ограничений
Методика проверки

Скрипт src/db_test_constraints.py пытается нарушить каждое ограничение
Для каждой проверки выводится ожидаемый результат, фактический результат и статус

Таблица результатов

| Ограничение | Ожидаемый результат | Фактический результат | Статус |
|------------|-------------------|---------------------|--------|
| UNIQUE на login | ошибка | ошибка | пройден |
| NOT NULL на last_name | ошибка | ошибка | пройден |
| CHECK на price | ошибка | ошибка | пройден |
| CHECK на quantity | ошибка | ошибка | пройден |
| FOREIGN KEY на role_id | ошибка | ошибка | пройден |
| ON DELETE RESTRICT | ошибка | ошибка | пройден |
| ON DELETE CASCADE | каскадное удаление | каскадное удаление | пройден |

Описание проверок

UNIQUE на login

Попытка вставить двух пользователей с одинаковым логином
Ожидается ошибка sqlite3.IntegrityError

NOT NULL на last_name

Попытка вставить пользователя без фамилии NULL
Ожидается ошибка sqlite3.IntegrityError

CHECK на price

Попытка вставить товар с отрицательной ценой
Ожидается ошибка sqlite3.IntegrityError

CHECK на quantity

Попытка вставить товарную позицию с отрицательным количеством
Ожидается ошибка sqlite3.IntegrityError

FOREIGN KEY на role_id

Попытка вставить пользователя с role_id которого нет в таблице roles
Ожидается ошибка sqlite3.IntegrityError

ON DELETE RESTRICT

Попытка удалить роль на которую ссылаются пользователи
Ожидается ошибка sqlite3.IntegrityError

ON DELETE CASCADE

Вставка заказа и позиции заказа, удаление заказа
Ожидается автоматическое удаление позиции заказа

Вывод

Все семь ограничений работают корректно
База данных защищена от вставки некорректных данных
