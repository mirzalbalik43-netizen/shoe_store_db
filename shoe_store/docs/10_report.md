# Отчет по практической работе №10: Процедуры и функции

## 1. Различия между функцией и процедурой

Функция— это вычисление. Она принимает аргументы и **обязательно возвращает значение (число, строку). Вызывается внутри `SELECT`. Не должна изменять состояние БД (делать INSERT/UPDATE).
Процедура— это действие. Она изменяет данные в таблицах (INSERT, UPDATE, DELETE). Вызывается командой `CALL`. В PostgreSQL может возвращать статус через параметры OUT, в SQLite (через Python) возвращает `True`/`False`.

## 2. Результаты Python-функций (Блок 1)

`calc_order_total`: Используется в запросе для вывода суммы каждой позиции: `SELECT order_id, calculate_total(price, quantity) FROM order_items;`
`get_category_count`: Используется для аналитики: `SELECT category, count_in_category(category) FROM products GROUP BY category;`
`format_phone`: Применяется к таблице клиентов: `SELECT first_name, format_phone(phone) FROM clients;` (превращает `89991234567` в `+7 (999) 123-45-67`).

## 3. Реализация транзакций (Блок 2)

`create_order`: Реализует атомарность. Если на шаге вставки в `order_items` произойдет сбой, `conn.rollback()` вернет базу в состояние до начала метода. Заказ не будет создан "наполовину".
`update_stock`: Содержит бизнес-валидацию. Если остаток уходит в минус, вызывается `ValueError`, срабатывает `except`, выполняется `conn.rollback()`, и данные на складе остаются неизменными.
