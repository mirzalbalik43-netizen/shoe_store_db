# Итоговый отчёт за день 4

## Что сделано:
1. Написан DDL-скрипт `db_init.py`, обладающий свойствами идемпотентности (сначала удаляет таблицы, затем создает).
2. Включена проверка ссылочной целостности (`PRAGMA foreign_keys = ON`).
3. Создана структура из 7 таблиц с ключами и индексами.
4. Написан скрипт автоматической проверки структуры `db_structure_check.py`.
5. Проверена работа ограничений (CHECK, UNIQUE, FOREIGN KEY).
6. База данных заполнена тестовыми данными.
7. Структура экспортирована в файл `db/schema.sql` программным путем.

## Принятые решения:
Порядок создания таблиц: от независимых (справочники `roles`, `sizes`) к зависимым (`order_items`). Это обязательно из-за наличия внешних ключей.
RESTRICT для заказов**: нельзя удалить пользователя, если у него есть заказы (сохранение истории).
CASCADE для состава заказа: при удалении заказа удаляются все его позиции (они не имеют смысла без заказа).
REAL для размера обуви: размеры могут быть дробными (например, 36.5).
TEXT для дат: SQLite не имеет отдельного типа DATE, формат ISO 8601 (YYYY-MM-DD) позволяет корректно сортировать.
Индексы: созданы на все внешние ключи (для JOIN) и на поля поиска (`category`, `manufacturer`, `order_date`).
