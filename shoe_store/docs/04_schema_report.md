# Отчёт о структуре базы данных (День 4)

Создана база данных `shoe_store.sqlite`.

Состав базы данных:
7 таблиц: `roles`, `sizes`, `products`, `users`, `stock_items`, `orders`, `order_items`.
Связи реализованы через внешние ключи (`FOREIGN KEY`) с каскадным удалением или запретом (`CASCADE`, `RESTRICT`).
Добавлены индексы для ускорения выборки (на внешние ключи и частые фильтры).

Порядок создания таблиц строго соблюдает зависимости (от справочников к зависимым таблицам).
