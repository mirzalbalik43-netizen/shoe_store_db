Какие стратегии удаления выбраны

ON DELETE RESTRICT
users role_id
Нельзя удалить роль если есть пользователи с этой ролью

stock_items product_id
Нельзя удалить товар если есть товарные позиции

stock_items size_id
Нельзя удалить размер если есть товарные позиции

orders user_id
Нельзя удалить пользователя если есть заказы

order_items stock_item_id
Нельзя удалить товарную позицию если есть позиции заказов

ON DELETE CASCADE
stock_items product_id
При удалении товара удаляются все его товарные позиции

order_items order_id
При удалении заказа удаляются все его позиции
