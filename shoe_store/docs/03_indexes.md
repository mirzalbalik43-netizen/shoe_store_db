Индексы для базы данных

Таблица       Поле            Тип       Обоснование
users         role_id         обычный   ускоряет JOIN с roles
orders        user_id         обычный   ускоряет JOIN с users
orders        order_date      обычный   ускоряет сортировку заказов по дате
products      category        обычный   ускоряет фильтрацию по категории
products      manufacturer    обычный   ускоряет фильтрацию по производителю
stock_items   product_id      обычный   ускоряет JOIN с products
stock_items   size_id         обычный   ускоряет JOIN с sizes
order_items   order_id        обычный   ускоряет JOIN с orders
order_items   stock_item_id   обычный   ускоряет JOIN с stock_items

Принципы создания индексов

Внешние ключи индексируются всегда
По ним выполняется JOIN между таблицами
Без индекса каждый JOIN сканирует всю таблицу

Поля для поиска индексируются
category и manufacturer в products
По ним выполняется фильтрация

Поля для сортировки индексируются
order_date в orders
По нему выполняется сортировка

Что не индексируется
Поля с малой кардинальностью например статусы
Поля которые редко используются в поиске
Все поля подряд не индексируются
Это замедляет вставку и увеличивает размер базы

Итого создано 9 индексов
