# Результаты простых запросов (День 6)

Запросы выполнены через src/db_run_queries.py. 
Все 20 SQL-запросов (объединение таблиц, подсчет статистики, группировка и фильтрация групп) выполняются без синтаксических ошибок. JOIN-запросы корректно связывают от двух до пяти таблиц. Агрегатные функции и оператор HAVING возвращают ожидаемые числовые значения. Данные выводятся в консоль в виде форматированных таблиц.
